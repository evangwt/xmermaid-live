# xmermaid-live 主题与连线几何设计

状态：已通过对话确认，待书面规格复核  
日期：2026-07-27

## 目标

这次变化同时改善 xmermaid-live 的工作台体验和 xmermaid 的边渲染正确性：

- xmermaid-live 首次访问默认使用酷感、克制的深色工作台，并提供配套浅色主题。
- 工作台主题默认带动 Mermaid 图表主题，用户仍可独立调整图表样式。
- 样式控制覆盖 xmermaid 现有渲染能力，而不另造一套不兼容的样式模型。
- xmermaid 的连线与箭头使用真实箭头几何计算连接位置，不再出现可见脱节。
- 新主题和几何修正通过正式 tarball 进入 xmermaid-live，不依赖相邻源码仓运行。

## 变化边界

本规格涉及两个本地仓库：

- `/Volumes/Data/Code/xmermaid`：主题预设、箭头几何、SVG 渲染与打包消费合同。
- `/Volumes/Data/Code/xmermaid-live`：工作台视觉、主题状态、样式抽屉、预览版本与浏览器验收。

本次不引入新前端框架、图标库、云端存储、用户账号、每张图独立主题或新的分享编码格式。分享链接继续携带文档和选中图表；SVG/PNG 导出使用当前可见样式。

## 参考原则

mermaid.live 提供了有用的工作台参考：预览是主视觉，配置有明确入口，画布操作贴近画布。xmermaid-live 保留自己已有的多图表列表、完整文本编辑和当前图表投影，不复制 mermaid.live 的品牌、示例库或营销区域。

├──────────────┼────────────────────────┼────────────────────────────┤

│              │                        │                            │

│   flowchart  │                        │                            │
│ ○ 图表 2     │                        │                            │
│   flowchart  │                        │                            │
├──────────────┴────────────────────────┴────────────────────────────┤
│ 诊断状态：没有诊断                                                │
└───────────────────────────────────────────────────────────────────┘
                                           ┌─ 图表样式 ────────────┐
                                           │ 预设  [深色] [浅色]    │

三栏关系、主题入口、抽屉位置和诊断层级是稳定约束。线框图中的尺寸、标点文案和空间比例只是示意。

样式抽屉覆盖预览右侧边缘，不重新压缩三栏。调整参数时预览实时更新，关闭抽屉不丢失样式。

### 移动端

移动端继续在“图表 / 编辑 / 预览”三个主面板间切换。样式入口打开全高面板，深浅主题保持可直接切换。样式面板关闭后返回原面板，不改变当前选中图表或编辑标签。

## 视觉系统

深色主题使用炭黑背景、分层中性色表面、青绿色主强调、珊瑚色错误和琥珀色警告。浅色主题使用冷白背景、清晰灰色边界、深墨文字和同一青绿色强调。两套主题使用共同的语义 token，但不用单一色相叠加层级。

工作台保持平整、紧凑，不在页面区域外叠装饰卡片，控件圆角不超过 8px。预览画布使用克制点阵，不使用大面积渐变、光斑或装饰图形。分段控件用于主题和曲线模式，色板用于颜色，菜单用于箭头类型，滑杆用于连续数值。

## 主题状态与数据流

```text
工作台主题：dark | light
          │
          ├──控制 HTML/CSS 语义变量
          │
          └──选择 xmermaid Dark / Light 基础图表主题
                                      │
用户图表样式覆盖 ─────────────────────┤
                                      ▼
                         当前有效 RenderTheme
                                      │
                                      ▼
                     PreviewRuntime 实时重新渲染
```

xmermaid 公共 API 增加正式 `LIGHT_THEME`，并重新设计 `DARK_THEME`。`DEFAULT_THEME` 保留现有入口和兼容语义。

xmermaid-live 的主题模型包含：

- `WorkspaceTheme`：`dark | light`，决定工作台 token 和基础图表预设。
- `DiagramStyleOverrides`：用户显式调整过的 `RenderTheme` 字段。
- 有效主题：基础预设与覆盖层的纯函数合并结果。

主题切换会替换基础预设，已调整字段保留，未调整字段跟随新预设。“重置”清空覆盖层，回到当前工作台主题的配套预设。

工作台主题和样式覆盖保存在浏览器本地。首次访问、无效值、版本不匹配或存储不可用时回退到深色默认值。不上传主题数据。

PreviewRuntime 的请求身份同时包含源码和有效主题。源码或主题任一变化都会发起新版本请求；旧请求不得更新预览、诊断或导出就绪状态。

## 箭头几何

### 现有根因

当前 Rust 布局层在不知道实际渲染主题的情况下，用固定 `DEFAULT_EDGE_GAP + DEFAULT_ARROW_SIZE` 提前计算 `path_end`。默认路径提前结束 18px，而实心三角箭头的轴向长度约为 8.7px，因此连线和箭头之间出现空隙。用户修改箭头类型或大小时，预先固化的 `path_end` 也不会与主题一起更新。

### 责任修正

```text
布局层
  路由点 + 节点边界交点 + 最终切线方向
                         │
                         ▼
渲染层读取当前主题和箭头类型
  ├─ 实心/三角：路径接到箭头底边中心，并轻微重叠
  ├─ 开放箭头：路径延伸到箭头尖端
  ├─ 圆形：路径接到圆形后缘
  ├─ 交叉：路径接到标记中心
  └─ 无箭头：路径直接到目标边界
```

布局层只提供路由和边界几何，不再固化主题的箭头尺寸。渲染层根据当前 `arrowStyle`、`arrowSize`、`edgeGap`、切线方向和线宽计算标记位置与路径连接点。

`edgeGap` 只表达连接标记与节点边界的留白，不在连线和箭头之间产生留白。新几何使用明确版本；旧布局字段继续可读，但新渲染不将旧的固化 `path_end` 当作可变主题下的权威连接点。

## 状态与失败处理

- 样式控件对数值进行范围限制，对颜色、枚举和本地存储结构进行验证。
- 主题重新渲染期间显示现有“渲染中”状态，不清空最后成功 SVG。
- 主题渲染失败时保留上一次成功 SVG，显示“预览未更新”和诊断，并禁用与当前源码或主题不匹配的导出。
- 抽屉、分段控件、菜单、色板和滑杆提供键盘操作、明确名称和不只依赖颜色的选中状态。
- 移动样式面板管理焦点，关闭时将焦点返回样式入口。

## 责任边界

### xmermaid

- 定义并导出深色、浅色图表预设。
- 保持 `DEFAULT_THEME` 的公共入口兼容。
- 让布局几何与渲染主题解耦。
- 根据箭头形状计算可验证的连接点。
- 打包时公开新主题和新几何行为。

### xmermaid-live

- 用 CSS 语义变量实现工作台深浅主题。
- 管理工作台主题、样式覆盖、本地持久化和样式抽屉。
- 将完整有效主题交给 xmermaid，不在应用层修补 SVG 几何。
- 将主题纳入预览新旧版本与导出就绪判断。

## 质量目标

### 功能适宜性—功能正确性

任意受支持的曲线、箭头尺寸和节点形状组合下，连线终点与箭头连接位置都不得出现正向空隙，箭头不得非预期穿入节点。证据是几何单测、SVG 属性测试和浏览器像素检查。

### 交互能力—易操作与包容性

用户能在桌面和移动布局中识别当前主题和样式覆盖，通过指针或键盘完成切换、调整、重置和关闭。证据是 DOM 语义测试、键盘端到端路径和桌面/移动截图。

### 兼容性—互操作性

xmermaid 的旧主题入口、打包子路径、WASM 资源和旧布局数据读取继续工作。xmermaid-live 只从打包产物消费新能力。证据是 xmermaid 消费者 smoke、公共类型测试和 xmermaid-live 生产构建。

### 可维护性—模块化与可测试性

布局层不依赖主题中的箭头尺寸，xmermaid-live 的主题合并是无 DOM 依赖的纯函数。证据是责任边界单测和代码评审。

## 验证设计

### xmermaid

- 几何单测覆盖 `bezier`、`step`、`straight`，`filled`、`triangle`、`open`、`circle`、`cross`，四个基本方向、斜向边和多路由点。
- 节点边界测试覆盖矩形、圆形、菱形、六边形和体育场形状。
- 渲染测试证明自定义 `arrowSize`、`edgeGap`、`arrowStyle` 和主题切换会重新计算几何。
- 主题测试锁定深色、浅色预设和 `DEFAULT_THEME` 兼容入口。
- 类型检查、JS 测试、Rust 测试、打包消费者 smoke 和 `git diff --check` 通过后生成 tarball。

### xmermaid-live

- 纯函数单测覆盖默认深色、主题切换、覆盖保留、重置、无效持久化数据和版本回退。
- PreviewRuntime 测试覆盖源码或主题变化的过期请求、错误保留和导出就绪判断。
- 应用 DOM 测试覆盖主题切换、抽屉、全部样式控件、重置、焦点返回和可访问名称。
- 生产端到端测试覆盖默认深色、浅色切换、自定义覆盖保留、刷新恢复、当前样式导出和移动面板。
- 浏览器截图覆盖桌面深色、桌面浅色和移动深色。SVG 坐标检查与画布像素检查证明连线与箭头连续。
- 最终通过 TypeScript、单元测试、Vite 生产构建、Playwright 端到端测试、静态子路径部署 smoke 和 `git diff --check`。

## 实施顺序

1. 在 xmermaid 中先用失败测试锁定箭头连接几何和可变主题行为。
2. 修正布局/渲染责任，增加深浅主题预设，跑完 xmermaid 验证。
3. 生成新 tarball，将 xmermaid-live 的文件依赖更新到该打包产物。
4. 在 xmermaid-live 中先写主题状态、预览版本和 UI 交互的失败测试。
5. 实现语义 token、主题持久化、样式抽屉和响应式交互。
6. 跑完两个仓库的目标测试与完整验证，再进行桌面/移动截图和箭头像素检查。

## 完成条件

- xmermaid-live 首次访问显示完整可用的深色工作台和配套深色图表。
- 浅色主题、图表样式覆盖、重置与本地恢复按已确认状态模型工作。
- 桌面和移动布局中的编辑、预览、诊断、分享和导出既有工作流不回归。
- xmermaid 的所有受支持箭头形状都与连线连续，主题尺寸变化不会重新产生脱节。
- xmermaid-live 从新打包 tarball 运行，两个仓库的目标验证和完整验证均通过，或任何不可运行项有明确证据和影响说明。
